# Changelog

## 1.0.0
- First release: Desmos-style graphing calculator for VRChat worlds (UdonSharp).
- Explicit, implicit, polar and parametric graphs; inequalities with shading; points.
- Variables with sliders (range, step, animation), user functions, lists and broadcasting, piecewise.
- Derivatives, integrals (including infinite bounds), sums and products.
- Tables and least-squares regression (Levenberg-Marquardt).
- Optional complex-number mode and degree mode.
- Networked multiplayer editing with ownership, lock, undo/redo.
- Editor builder (Tools > Graphing Calculator) and floating "how to use" / "how it works" info panels.
