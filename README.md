# Udon Graphing Calculator

A Desmos-style graphing calculator for VRChat worlds, written in UdonSharp. It supports explicit, implicit, polar and parametric graphs, inequalities, sliders, lists, tables, regression, calculus and complex numbers, with networked multiplayer editing. All the math runs inside Udon.

## Install (VRChat Creator Companion)

1. Open **https://dfghiatus.github.io/Udon-Graphing-Calculator/** and click **Add to VCC**, or add this repository URL in *VCC → Settings → Packages → Add Repository*:
   `https://dfghiatus.github.io/Udon-Graphing-Calculator/index.json`
2. In your world project, choose *Manage Project* and add **Udon Graphing Calculator**.
3. Drag `Packages/Udon Graphing Calculator/Runtime/GraphingCalculator.prefab` into your scene, or use *Tools → Graphing Calculator → Build Calculator In Scene*.

Requires VRChat Worlds SDK 3.10+ and Unity 2022.3.
